# Gabriel Clementino | Data & BI Portfolio

Portfólio profissional de Gabriel Clementino, Analista de Dados, BI e Inteligência de Negócios.

O projeto apresenta sua trajetória profissional, capacidades técnicas e uma seleção de projetos de Business Intelligence, dashboards, ETL, modelagem de dados e análise de negócios.

## Sobre

Gabriel Clementino atua na interseção entre operação, negócio e tecnologia, conectando requisitos, dados e decisões mensuráveis.

Entre as principais áreas de atuação estão:

- Business Intelligence e dashboards executivos e operacionais
- Power BI, Power Query e modelagem dimensional
- SQL, Python e automação de relatórios
- Integração e tratamento de dados por meio de pipelines ETL
- Definição e acompanhamento de KPIs
- Análise de negócios, processos e performance
- Prototipação e data storytelling com Figma

## Projetos apresentados

- **Mars Company:** dashboard operacional com pedidos, receita, entregas, cancelamentos, devoluções e eficiência.
- **AdventureWorks:** análise de vendas, clientes, produtos, territórios e revendedores.
- **Piracanjuba:** acompanhamento de capacitação, conclusão de treinamentos e desempenho.
- **VitalFit:** visão financeira com receita, ticket médio, lifetime value, clientes ativos e churn.

## Tecnologias do projeto

O site é uma aplicação estática construída com HTML, CSS e JavaScript, sem dependências externas de backend. As fontes tipográficas são carregadas pelo Google Fonts e as imagens utilizadas ficam na pasta `assets`.

## Como executar localmente

Não é necessário instalar dependências. A forma mais simples de visualizar o projeto é iniciar um servidor HTTP na pasta raiz:

```bash
python3 -m http.server 3000
```

Depois, abra `http://localhost:3000` no navegador.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Copie todos os arquivos deste projeto para a raiz do repositório.
3. Faça o commit e o push para a branch principal:

```bash
git init
git add .
git commit -m "Create Gabriel Clementino data portfolio"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

4. No GitHub, acesse **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/root`.
7. Salve e aguarde a publicação.
